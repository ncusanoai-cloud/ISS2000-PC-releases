# ISS 2000 PC — releases

Download page for the PC beta of International Superstar Soccer 2000 (N64).

- Get the latest package from **Releases** (right side of this page).
- **No ROM is included.** You need your own original ISS 2000 cartridge dump.
- Unzip to a folder and run `Start.exe`. Your settings and saves from earlier betas are kept.

This repository contains only release packages and `latest.json`
(the file the launcher reads to tell you a new version is available).
No source code is published here.
